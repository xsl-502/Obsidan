## 四、各章节具体写作计划

### 第 1 章 绪论

写作重点：

1. 从数字经济、数字普惠金融发展、金融风险防控、商业银行流动性管理四个角度引入。
2. 强调数字普惠金融既可能通过金融科技和金融服务可得性提升银行经营效率，也可能通过互联网理财、线上信贷、金融脱媒和资金分流加剧银行流动性压力。
3. 说明本文选择上市商业银行年报和北大数字普惠金融指数进行实证研究。

需要使用的数据和材料：

- 北京大学数字普惠金融报告；
- 国家金融监督管理总局商业银行监管指标；

### 第 2 章 文献综述

写作重点：

1. 不要简单罗列文献，要形成研究脉络。
2. 先写数字普惠金融研究，再写商业银行流动性风险研究，最后写数字金融影响银行风险的研究。
3. 文献评述必须指出本文研究切入点：现有研究更多关注银行风险承担、信用风险和流动性创造，对传统流动性风险指标的直接研究相对不足。

### 第 3 章 理论分析与研究假设

写作重点：

围绕“数字普惠金融如何影响商业银行流动性风险”构建逻辑链条。

建议提出以下假设：

H1：数字普惠金融发展会显著影响商业银行流动性风险。

H2：数字普惠金融覆盖广度、使用深度和数字化程度对商业银行流动性风险的影响存在差异。

H3：数字普惠金融可能通过影响商业银行风险承担水平影响其流动性风险。

H4：数字普惠金融对不同类型商业银行流动性风险的影响存在异质性。

理论机制：

1. 存款竞争机制：数字普惠金融和互联网理财可能分流传统银行存款，削弱稳定负债来源。
2. 信贷扩张机制：数字金融改善信息匹配，也可能推动银行扩大信贷投放，影响资产负债期限结构。
3. 风险承担机制：数字金融竞争压缩银行利差，可能诱导银行提高风险承担。
4. 经营效率机制：数字化技术提升风控、客户识别和流动性管理能力，可能降低流动性风险。

本章建议字数：

4000-6000 字。

### 第 4 章 研究设计

写作重点：

本章应当先写，因为它最依赖当前已经准备好的数据。

必须写清楚：

1. 样本为 2014-2023 年中国 A 股上市商业银行；
2. 数据来自上市银行年报和北京大学数字普惠金融指数；
3. 因部分银行未连续披露传统流动性比例，本文构建非平衡面板；
4. 解释变量为银行总部城市对应的数字普惠金融指数；
5. 被解释变量为 `liquidity_risk = - liquidity_ratio`；
6. 控制变量包括资本充足率、不良贷款率和成本收入比。

基准模型：

```text
LiquidityRisk_it = α + β DFI_ct + γ Controls_it + μ_i + λ_t + ε_it
```

其中：

- `LiquidityRisk_it` 表示银行 i 在年份 t 的流动性风险；
- `DFI_ct` 表示银行总部城市 c 在年份 t 的数字普惠金融发展水平；
- `Controls_it` 表示银行层面控制变量；
- `μ_i` 表示银行固定效应；
- `λ_t` 表示年份固定效应。

本章建议字数：

4000-6000 字。

### 第 6 章 稳健性检验

当前数据条件下，建议选择可实现的稳健性检验：

1. 替换核心解释变量：分别使用覆盖广度、使用深度、数字化程度。
2. 加入更多控制变量：加入 `roa`、`roe` 或 `ln_total_assets`，但需说明样本量会缩小。
3. 剔除国有大型商业银行，只保留股份制商业银行。
4. 剔除 2020 年特殊冲击年份。
5. 使用核心解释变量滞后一期。

不建议现在强行做工具变量法，因为样本量较小，工具变量选择也较难说服。

本章建议字数：

3000-5000 字。

### 第 7 章 机制检验与异质性分析

机制检验建议优先做两个：

1. 风险承担机制：
   - 机制变量：`npl_ratio`
   - 逻辑：数字普惠金融可能影响银行风险承担，风险承担变化进一步影响流动性风险。

2. 经营效率机制：
   - 机制变量：`cost_income_ratio`
   - 逻辑：数字技术可能提升银行经营效率，降低成本收入比，从而缓解流动性风险。

异质性分析建议谨慎做：

1. 股份制商业银行与国有大型银行；
2. 总部城市数字普惠金融水平高低分组；
3. 高资本充足率银行与低资本充足率银行。

注意：

由于当前样本量较小，异质性分析应定位为“进一步分析”，不要过度解释。

本章建议字数：

3000-5000 字。

### 第 8 章 研究结论与政策建议

写作重点：

结论必须紧扣实证结果，不能先验发挥。

政策建议建议分三类：

1. 监管部门：

   - 加强互联网金融平台资金流动监测；
   - 建立中小银行流动性风险预警体系。

2. 商业银行：
   - 优化负债结构；
   - 提高核心存款稳定性；
   - 加强流动性压力测试；
   - 提升数字化风控和资产负债管理能力。

3. 数字金融平台：
   - 强化合规经营；
   - 避免无序竞争和监管套利；
   - 与商业银行形成合作互补关系。

本章建议字数：

3000-5000 字。

## 五、实证分析执行计划

### 第一步：运行描述性统计

使用：

`02_数据集/描述性统计_基准回归样本.csv`

或在 Stata 中运行：

```stata
summarize liquidity_risk liquidity_ratio dfi_index dfi_breadth dfi_depth dfi_digitization ///
    capital_adequacy_ratio npl_ratio cost_income_ratio roa roe ln_total_assets
```

### 第二步：运行相关性分析

```stata
pwcorr liquidity_risk dfi_index capital_adequacy_ratio npl_ratio cost_income_ratio, sig
```

### 第三步：运行基准回归

```stata
reg liquidity_risk dfi_index, robust
reg liquidity_risk dfi_index capital_adequacy_ratio npl_ratio cost_income_ratio, robust
reg liquidity_risk dfi_index capital_adequacy_ratio npl_ratio cost_income_ratio i.year, robust
xtreg liquidity_risk dfi_index capital_adequacy_ratio npl_ratio cost_income_ratio i.year, fe robust
```

### 第四步：运行分维度回归

```stata
xtreg liquidity_risk dfi_breadth capital_adequacy_ratio npl_ratio cost_income_ratio i.year, fe robust
xtreg liquidity_risk dfi_depth capital_adequacy_ratio npl_ratio cost_income_ratio i.year, fe robust
xtreg liquidity_risk dfi_digitization capital_adequacy_ratio npl_ratio cost_income_ratio i.year, fe robust
```

### 第五步：稳健性检验

可依次尝试：

```stata
xtreg liquidity_risk dfi_index capital_adequacy_ratio npl_ratio cost_income_ratio roa i.year, fe robust
xtreg liquidity_risk dfi_index capital_adequacy_ratio npl_ratio cost_income_ratio ln_total_assets i.year, fe robust
drop if year == 2020
xtreg liquidity_risk dfi_index capital_adequacy_ratio npl_ratio cost_income_ratio i.year, fe robust
```
