# 变量字典

| 变量名 | 中文含义 | 类型 | 说明 |
|---|---|---|---|
| code | 股票代码 | 识别变量 | 上市银行 A 股代码 |
| bank_name | 银行名称 | 识别变量 | 上市银行简称 |
| year | 年份 | 时间变量 | 2014-2023 |
| hq_city | 总部城市 | 匹配变量 | 用于匹配城市级数字普惠金融指数 |
| hq_province | 总部省份 | 匹配变量 | 用于地区说明 |
| bank_type | 银行类型 | 分类变量 | 股份制商业银行或国有大型商业银行 |
| is_state_owned_large | 是否国有大型银行 | 虚拟变量 | 国有大型商业银行为 1，否则为 0 |
| liquidity_ratio | 流动性比例 | 被解释变量基础指标 | 年报披露的商业银行流动性比例 |
| liquidity_risk | 流动性风险 | 被解释变量 | `- liquidity_ratio` |
| dfi_index | 数字普惠金融总指数 | 核心解释变量 | 北大数字普惠金融指数，城市级 |
| dfi_breadth | 覆盖广度 | 分维度解释变量 | 北大数字普惠金融指数 |
| dfi_depth | 使用深度 | 分维度解释变量 | 北大数字普惠金融指数 |
| dfi_digitization | 数字化程度 | 分维度解释变量 | 北大数字普惠金融指数 |
| dfi_payment | 支付指数 | 拓展解释变量 | 北大数字普惠金融指数 |
| dfi_credit | 信贷指数 | 拓展解释变量 | 北大数字普惠金融指数 |
| dfi_investment | 投资指数 | 拓展解释变量 | 北大数字普惠金融指数 |
| dfi_insurance | 保险指数 | 拓展解释变量 | 北大数字普惠金融指数 |
| total_assets | 总资产 | 控制变量 | 来自年报，自动抽取后清洗 |
| ln_total_assets | 银行规模 | 控制变量 | 总资产自然对数 |
| roa | 总资产收益率 | 控制变量 | 来自年报 |
| roe | 净资产收益率 | 控制变量 | 来自年报 |
| capital_adequacy_ratio | 资本充足率 | 控制变量 | 来自年报 |
| core_tier1_capital_ratio | 核心一级资本充足率 | 控制变量 | 来自年报 |
| npl_ratio | 不良贷款率 | 控制变量/机制变量 | 来自年报 |
| cost_income_ratio | 成本收入比 | 控制变量/机制变量 | 来自年报 |
| provision_coverage | 拨备覆盖率 | 控制变量 | 来自年报 |
| liquidity_ratio_page | 流动性比例页码 | 审计字段 | 对应 PDF 页码 |
| liquidity_ratio_evidence | 流动性比例原文依据 | 审计字段 | 年报原文片段 |
| pdf_file | 年报文件路径 | 审计字段 | 年报 PDF 来源 |
| data_quality_note | 数据质量说明 | 审计字段 | 记录被置空的异常值 |
